= PDF Assets

This directory holds PDF branding assets that the PDF theme references
directly.

== Logo files

`eclipse-foundation-logo.svg` is the Eclipse Foundation logo used on the
cover pages. It lives here rather than alongside the other images because
asciidoctor-pdf resolves a title page background image relative to the theme
directory, not to `imagesdir`; the theme refers to it as
`../assets/eclipse-foundation-logo.svg`.

The Eclipse ThreadX cover logo is content rather than a theme asset, so it
stays in `rtos-docs/home/modules/ROOT/assets/images/` and the assembler
configs reference it as `image:home::eclipse-threadx-logo.svg[]`.

Both are SVG. A raster logo is not usable here: the PNGs that upstream ships
are interlaced, which prawn cannot decode, and the logos may not be
re-encoded under the Eclipse Foundation Trademark Usage Policy. See
`pdf/NOTICE.adoc` for trademark attribution and the source ZIP files.

== Custom cover pages

For custom front/back PDF covers, place image or PDF files in this directory
and reference them in the assembler configs:

[source,yaml]
----
assembly:
  attributes:
    front-cover-image: 'image:home::pdf/front-cover.png[]'
    back-cover-image:  'image:home::pdf/back-cover.png[]'
----
